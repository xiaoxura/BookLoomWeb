更新日志

这个工具的每次变化都记在这里。当前版本 v%APP_VERSION%。

  1. v0.2.0 2026-11-04

    元数据、内嵌目录与封面编辑器

    把「书做得更像一本书」的三件事补齐，草稿和旧版本保持兼容。

    • 书籍元数据：在书名 / 作者之外可填写简介、系列、出版社、标签和出版日期；EPUB 3 会写进 dc:description、dc:publisher、dc:subject、dc:date 和系列字段，EPUB 2 保留基础字段。导入 EPUB 时也会读取这些信息，兼容 calibre 系列列。
    • 内嵌目录页：EPUB 3 / EPUB 2 都在封面之后、正文之前生成可点击的 toc.xhtml，卷 / 章层级与 nav / NCX 一致；重新导入时不会把目录页当成章节。
    • 封面编辑器：竖排书名 / 色块两种模板上可切换原木、墨夜、深海、酒红、松林配色，调整标题字号和作者位置，右侧实时预览；参数随草稿保存，导出的 JPEG 与预览一致。
    • 兼容性：旧草稿的 coverOptions 缺失时自动补默认值；M1–M3 的书架、转换和导出链路不变。
  2. v0.1.0 2026-11-04

    校对、书架与格式扩展

    第一个功能版本：把「改得动、找得到、导得出」补齐。

    • 通用撤销 / 重做：改标题、分章、合并、删除、升降级、替换和重编号都进历史，最多 50 步；支持 Ctrl/Cmd+Z、Shift+Ctrl/Cmd+Z，目录面板也有按钮。
    • 批量替换 / 清洗：按标题 / 正文 / 全部范围查找替换，支持正则、大小写、命中预览和前后文；执行前自动记录，可一次撤销。
    • 全书体检 + 章号校验：检查缺号、重复、空章、标题重复、异常长短、卷内无章和广告残留；可按顺序重编号，保留中文 / 阿拉伯数字风格。
    • 多草稿书架：每本书的草稿、原文和字体分开存进 IndexedDB；顶栏书架可打开、改名、删除，并显示本地占用；旧版单草稿会自动迁移。
    • DOCX 导入：按 Heading 1 / 2（含中文「标题 1 / 2」和大纲级别）还原卷章；无标题样式时退化为单章并提示。
    • DOCX / 单文件 HTML 导出：DOCX 用 Word 标题样式，HTML 内联 CSS 且目录可跳转；单本和批量都支持。
    • 繁简转换：导入时可选保持原样 / 转简体 / 转繁体，章节标题和正文一起转换；opencc-js 词典按需加载，原文不改。
    • 快捷键：↑/↓ 或 J/K 切章、/ 聚焦搜索、Ctrl/Cmd+S 导出、Esc 关闭浮层。
  3. v0.0.2 2026-11-04

    排版与识别的增强

    参照 kaf-cli 的成熟做法补了一轮细节，重点是让导出的书更像一本书。

    • 章号单独一行：开启后「第1章」和标题分两行显示，长标题更清爽。
    • 附加 CSS：可以往 EPUB 样式表末尾追加自己的规则，解决不同阅读器的缩进、字距差异。
    • 嵌入字体：上传 ttf / otf / woff / woff2，导出时打包进 EPUB 并在正文使用；字体单独存本地，不会拖慢草稿保存。
    • 色块封面：新增 Orly 风格的纯色封面，颜色由书名决定，完全本地生成。
    • 识别更稳：「第X部分 / 部门 / 部队」不再被当成卷；补上「完本感言」「最终章」和英文 Section / Page。
    • 文件名解析：《书名》（校对版全本）作者：远瞳.txt 能直接拆出书名和作者。
    • 更多预设：新增裸数字标题（123），数字标题预设也接受「12、」。
    • 页面不再整体滚动：工作区铺满窗口，章节、预览、设置各自滚动；落地页和更新日志也只在内容区滚动，页头页脚常驻。
  4. v0.0.1 2026-11-04

    第一个版本

    从「只能把 TXT 变成 EPUB」开始，到现在两边都能走。第一版把基础能力一次搭齐：

    • TXT ⇄ EPUB：TXT 可以导出 EPUB 3 / EPUB 2；EPUB 可以拆回 TXT、Markdown，或重新排版后再导出 EPUB。
    • 编码识别：自动判断 UTF-8、GBK / GB18030、Big5、UTF-16，识别不准时可以手动切换。
    • 章节识别：按「标题形态 + 密度」打分分章，支持卷 / 章两级、目录页剔除、空行分章兜底；「第1章我的天呐」会自动补成「第1章 我的天呐」。
    • 人工校对：改标题、合并、删除、升降级，从任意段落分章或设为标题，支持搜索和输入章号跳转。
    • 漏章诊断：自动列出像标题却没被识别的段落，一键修正。
    • EPUB 导入：按 spine 顺序拆章节，标题和层级优先取 nav / NCX，没有目录时用正文标题兜底；封面、书名、作者一并带出来，带 DRM 的书会直接报错。
    • 排版与封面：行高、段距、首行缩进、字体、两端对齐可调；可以自动生成竖排书名封面，也可以上传自己的图。
    • 批量与草稿：一次拖入多本 TXT / EPUB 批量转换；解析结果和编辑自动存进 IndexedDB，刷新后接着改。
    • 规则与隐私：内置站点预设，也能手写 JSON 规则；所有转换都在浏览器里完成，文件不上传，断网可用。
